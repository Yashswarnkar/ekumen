## CHANGES

- `internal/core/impact.go` (new): `Gates` (the union of `blocks` and `blocked_by`, #63), `ImpactOf` (unfinished tasks only, using observations; direct vs. transitive; one shortest path per task; contract_impact kept as context and never walked), `WaitsOn` (the open-blocker tree).
- `internal/core/priority.go`: `BlockedByDecision`, `Priority`, `PendingDecisions` and `Inbox` now take `Observed` and use `ImpactOf`.
- `internal/core/apply.go`: `ApplyEffectOf` amends every task in `Gates`: `blocks` first, then tasks whose `blocked_by` names the decision.
- `internal/observe`: `LinkTask` matches the recorded branch, then a `-<n>` stack suffix, then a `<id>:` title. Among matches, open or draft beats merged, merged beats closed, then the earlier rule wins, then the higher number. `BranchReader` with `GH.DecisionRaises` makes two read-only `gh api graphql` calls (file names, then only the blobs not already in the local log). `StaticBranches` is for tests.
- `internal/project/inbox.go` (new): the inbox with `what`, `why`, `unblocks`, `path`, `direct`, `contract_context`, `options` and `recommendation`, and for branch decisions `on_branch`, `pr`, `answerable: false` and `blocked_by`. Also `BranchDecisions` (lazy, one read per command), `WhyOf`, and `OnBranch`.
- `internal/cli`:
  - new `ekumen why <id>`
  - new plain inbox printer, with no `p=`
  - `task show` prints the PR and the rule that linked it
  - `decision show` falls back to a branch decision, with a warning
  - `decision answer` refuses a branch decision (exit 2, naming D-branch-decision-answer)
- `internal/mapview/template.html`: decision cards show the plain "why" instead of "priority N".
- `docs/cli.md`: inbox, ranking rules, branch decisions, the `why` command and the PR linking rules.
- Golden updates are all intended: applied or superseded decisions now hold up nothing, and contract_impact no longer counts.
