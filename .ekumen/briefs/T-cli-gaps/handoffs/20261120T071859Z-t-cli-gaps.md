## STATUS

Done, in review (draft PR #10). Every command in the brief, as amended, is implemented with golden `--json` tests and lane tests. `ekumen check` runs in CI. `go test -race ./...`, `go vet ./...` and `gofmt -l .` are clean, and `bin/ekumen check` is clean on the branch.

## OUTPUT

- **`decision apply <id> [--amend-text-file f]`**, run as `loop:<session>`. It writes one §B amendment per task in `blocks`, using the given text or a generated line. Then it writes `DecisionApplied {amended_tasks, unblocked_tasks, notified_sessions: []}`. `unblocked_tasks` lists tasks that were blocked before the apply and are not after it.
  - It refuses pending and superseded decisions.
  - It is idempotent: a second apply prints `events: []` and writes no files. A test covers this.
  - The amendments are recorded as `orchestrator:<same id>`, so that id must hold the orchestrator claim. See D-apply-amend-lane.
- **`task defer`**, **`task attach`** (a repeat with the same session and adapter is a no-op), **`contract draft --file [--text-file]`** (it writes the body file and never overwrites one), **`contract block`** (shares its logic with `task block`), and **`external add|update|resolve`**. `external update` records only the fields that change.
- **Id prefixes:** question and route ids accept a unique prefix, in any case (`project.MatchPrefix`). An ambiguous prefix exits 1 with code `usage` and lists the matches.
- **Entry front matter:** `task`, `author` and `date` are each optional. When a key is given it is validated: the task must match, the author must be the actor, and the date must be a date. When a file has no front matter, all three are added. This applies to `task amend`, `task handoff` and `decision apply`, and is documented in docs/cli.md.
- Entry file names now take their timestamp from the command's clock (`WriteEntryAt`), so they match the event time and tests are deterministic.
- **CI:**
  - The Go cache is on, and `go test -race` runs.
  - A new step runs `scripts/ci-check.sh .`. It prints the `ekumen check --json` output and fails if check exits non-zero. It also fails when `.ekumen/events/` exists but is empty, and skips with a notice when that folder doesn't exist.
  - `cmd/ekumen/cicheck_test.go` runs the script against four fixtures, one of them a lane violation.
  - The step is documented in docs/development.md.
