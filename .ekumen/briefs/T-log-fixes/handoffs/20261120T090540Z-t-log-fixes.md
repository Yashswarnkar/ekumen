# T-log-fixes handoff 2 · review of PR #11

## STATUS

Done, in review: all 10 review findings of PR #11 are fixed in commit d1f8374. The branch is rebased on main. Tests (race), vet, gofmt, `check` and `ci-check.sh` are clean, and on a copy of the real log `decision apply D-lane-gaps` still takes effect.

## SUMMARY

1. **Alias grouping.** `SortEvents` groups an event addressed to an alias with the item whose creating event declares that alias, so the event lands after the item is created. An approve of `T-old` is applied to `T-new`, with no phantom task. An event addressed to an alias that nobody declares is reported as `orphan-step`. Test: `TestAliasCausalOrder_DImportedEventTimeOrder`.
2. **Loop amendment lane.** The loop may write `TaskAmended` only when `by_decision` names a decision that:
   - is decided or defaulted, and
   - blocks the task (the task is in its `blocks`, or the decision is in the task's `blocked_by`).

   Anything else is a `lane` conflict. Tests: the core lane test, and a CLI test in which `loop:x` amends an unrelated task and the amendment is reported.
3. **Fragment scoping.** Every CSS rule is scoped to `.ekumen-map`, including custom properties and dark mode. The page has no fixed element ids: its script queries elements inside its own wrapper, and SVG marker ids are unique per render. A test parses every selector.
4. **orphan-step exemptions.** `RoutedToOwner`, `RouteResolved` and `ConflictDetected` are exempt.
5. **Project name.** The name is taken, in order, from `project:` in `.ekumen/config.yaml` (optional and committed), then from the remote's repository name when the root is a repository top (contains `.git`), then from the folder name. A monorepo subfolder therefore gets its folder name. `registry.yaml` is no longer read. The order is documented in `docs/cli.md`.
6. **Git calls.** `load()` runs only `git remote get-url`; `map` reads the default branch and the prefix.
7. **No re-sort.** `OrphanStepConflicts` no longer re-sorts the log; its output is sorted by event id.
8. **Clear error for a second decision.** `contract version` gives a clear error when the same version and text were already recorded by another decision.
9. **No freeze action without a file.** A contract with no file gets no freeze action.
10. **Shared helpers.** `Snapshot.BriefPath` and `Snapshot.AllTaskIDs`, which uses `sortedKeys`, replace the duplicated code.
