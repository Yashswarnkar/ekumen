## SUMMARY

1. **Causal order.** Within a subject, events keep time order. The one exception: an event stamped before its own prerequisite moves to right after it.
   - `DecisionApplied` waits for its decide or default.
   - `QuestionAnswered` waits for its `QuestionAsked`.
   - Any other item event waits for the item's creating event.
   - Routing, conflict and project events never move.

   `TestDecideApplySupersede_DImportedEventTimeOrder` checks that decide → apply → supersede keeps the applied info, including when the apply is stamped before the decide.
2. **Map script scope.** The map script runs inside an IIFE. `TestTwoFragmentsOnOnePage_TLogFixes7` checks that every script is wrapped. When `node` is installed, it also runs two fragments in one global scope. I confirmed the test fails without the IIFE.
3. **Map links.** Links point at the commit the map was generated from. Without a commit they use origin's default branch (`origin/HEAD`). With neither, there are no links; the code never guesses `main`.
4. **Freeze action.** The freeze action for a pending version now also requires the contract to be frozen and to have no open blockers.
5. **Lead name.** `Lead()` reads `lead:` from `.ekumen/config.yaml`, then falls back to the events. It no longer reads `registry.yaml`.
6. **Alias map.** The alias map is keyed by (kind, alias).
7. **Cleanups.**
   - Version errors now name the actual fix: add `version: N`, or set it to N or higher.
   - Each run makes one `git remote get-url` call: `Env.Git` is now a git runner and `Env.Remote` is gone.
   - `contract freeze` and `contract version` hash the bytes they already read (`files.HashBytes`).
   - The duplicate `loopRole` is removed.
